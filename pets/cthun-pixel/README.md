# 克苏恩

Hearthstone C'Thun compressed into a tiny front-facing pixel Old God: golden slit eye, purple flesh, ivory carapace and four main tentacles.

将本文件夹中的 `pet.json` 和 `spritesheet.webp` 一起安装。详见[安装说明](../../README.md#安装)。

格式：Codex v2，1536 × 2288，8 × 11 格；每格 192 × 208。包含 9 组标准动画、1 个中立帧与 16 个方向帧。
